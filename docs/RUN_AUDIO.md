# 달리기 반복음

- 음원: `Assets/Sound/Run Sound.wav` (모노, 약 1.52초).
- `SoundType.Run`을 Stage1 SoundPlayer에 등록했다. Volume 0.35, 공통 masterVolume 0.8, 거리 감쇠 없음.
- PlayerMovement.IsRunningWithInput는 기본 이동 입력 방향으로 실제 움직이는지 확인한다. 최고 속도 조건은 없다. 일반 점프 중에도 유지되며, 벽 접촉·벽점프·입력 해제·이동 잠금은 제외한다.
- PlayerRunAudio의 Inspector > Start Delay에서 대기 시간을 조절한다. NetworkPlatformPlayer 프리팹에는 0.1초로 설정했다. 0이면 즉시 재생한다. 속도 비율 조건은 없으며 공중에서도 이동을 이어가면 시간이 누적된다. 소리는 지상에서만 재생하고, 정지·이동 잠금 시 누적 시간을 초기화한다.
- 시작/정지 변경만 Command → SyncVar로 공유한다. 관찰자는 받은 상태를 재생하되 사망·교대 중에는 재생하지 않는다.
- SoundPlayer의 기존 고정 풀에서 채널 하나를 빌려 AudioSource.loop로 반복하고, 중지 시 즉시 반납한다. 반복 채널은 일시 정지 중에도 다른 음원이 빼앗지 못한다.
- 기존 NetworkPlatformPlayer 프리팹에 PlayerRunAudio만 추가했다. 다른 씬은 수정하지 않았다.

## 이전 조건에서의 검증 기록

같은 PC의 호스트와 Multiplayer Play Mode 클라이언트 1개로 검증했다. 두 실제 PC나 빌드 검증은 아니다.

- 호스트 소유자와 원격 소유자 모두 실제 PlayerMovement 가속/감속을 실행했다. 테스트에서 키보드 대신 입력 값을 공급했고 임시 평지에서 측정했다. 테스트 입력·지형은 저장하지 않았다.
- 최고 속도 판정부터 최초 재생까지 호스트 약 1.004초, 원격 약 0.998초(프레임·샘플링 차이).
- 조건을 1초 유지하지 않은 짧은 이동은 양쪽 모두 재생되지 않았다.
- 좌/우 달리기, 입력 해제, 방향 변경, 반복 재생 및 루프 경계를 확인했다. 주기적 Play 호출이 아니라 동일 채널의 timeSamples가 반복되는 것을 확인했다.
- 벽점프 모터 진입 시 정지하고, 정상 이동 복귀 후 1초를 다시 센 것을 확인했다. 벽점프 모터는 테스트에서 직접 호출했다.
- 사망·다음 공격자 교대 시 이전 플레이어의 반복음이 정지했다.
- 양쪽 실행에서 같은 Run Sound가 재생됐다. 수집한 검증 중 런타임 오류는 각각 0건, 컴파일 실패 없음.
- Console의 별도 connection.state_change 오류는 Unity AI 도구의 MCP Relay 포트 충돌(EADDRINUSE) 로그였다. 게임 사운드 범위 밖이라 수정하지 않았다.

## 현재 사망 그림

DeathSequence가 실제로 참조하는 그림은 Doll/Knight 각각 Backward/Forward의 `Body12_v2.png` 4장과 `Death_Orbit_Star_v2.png`다. 몸 12프레임을 한 번 재생한 뒤 마지막 자세를 유지하고 별은 별도 SpriteRenderer 3개로 회전시킨다.

현재 참조를 검사해 사용하지 않는 사망 연출 자료 24개와 해당 meta를 삭제했다. v1 시트, v1/v2 Preview GIF, v2 30프레임 합성 시트·별 루프 GIF, HTML 미리보기와 제작용 프롬프트·타이밍 자료다. 실제 사용하는 위 5개 이미지는 유지했다.

## 이전 조건 변경 기록

- 정확한 최고 속도 조건에서 지상 98% 이상으로 완화했다. 1초 대기와 즉시 정지 방식은 유지한다.
- 공중으로 뜨면 즉시 멈추고 대기 시간을 초기화한다. 착지 후 조건을 다시 1초 유지해야 재생한다.
- 조건 변경 후 솔로 Play Mode에서 속도를 제어해 97%에서는 미재생, 98%를 약 1.006초 유지한 뒤 재생됨을 확인했다. 실제 점프 중 291개 샘플에서 재생은 없었고, 착지 후 재시작과 98% 미만 감속 시 정지도 확인했다. 검증 중 런타임 오류는 없었다. 테스트용 이동 수치는 복제한 런타임 설정에서만 변경했고 저장하지 않았다.
- 사망 이미지 정리 후 몸 Sprite 48개와 별 참조가 모두 유효하고 컴파일 실패가 없음을 확인했다.

## 이전 조건: 달리기 0.5초 + 지상 재생

- 최고 속도/98% 조건을 제거했다. 기본 이동 입력 방향으로 실제 움직이기 시작하면 시간을 센다.
- 일반 점프 중에도 달리기를 이어가면 시간이 누적된다. 공중에서는 소리만 끄고, 0.5초를 넘긴 상태에서 착지하면 추가 대기 없이 재생한다.
- 이동 입력 해제·이동 중단·사망·교대 시 누적 시간을 초기화한다. 벽점프는 기존처럼 기본 달리기에서 제외한다.
- 솔로 Play Mode에서 달리기 약 0.1초 뒤 실제 점프를 입력했다. 공중 165개 측정 샘플에서 소리는 없었고 누적 시간은 0.5초에 도달했다. 착지와 최초 재생이 같은 측정 프레임(약 1.04초)에 확인됐다. 입력 해제 시 정지, 다시 달릴 때 재생도 확인했다. 컴파일 실패와 검증 중 런타임 오류는 없었다.
